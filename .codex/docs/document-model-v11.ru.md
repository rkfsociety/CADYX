# Модель документа CADYX v11 — назначение материала сборки

Документ v11 обновляет граф сборки с версии 2 до версии **3**. В каждом определении детали появляется явное nullable-поле `material`. При чтении более ранние документы мигрируются в памяти; для деталей v10 значение материала устанавливается в `null`. Версия оболочки проекта остаётся 1; контракт сопряжений v10 и прежние контракты документа остаются действующими.

```json
{
  "assembly": {
    "version": 3,
    "units": "mm",
    "parts": [{
      "id": "part:<uuid>",
      "name": "Кронштейн",
      "body_id": "body:<uuid>",
      "material": {
        "name": "Алюминий",
        "density_kg_m3": 2700,
        "source": "Технические данные поставщика"
      }
    }],
    "subassemblies": [],
    "instances": [],
    "mates": []
  }
}
```

`material` — это `null` либо явно заданный объект с названием, положительной `density_kg_m3` и источником `source`. CADYX не подбирает материал и плотность автоматически. Для расчёта массы сборки необходимо назначить данные материалов; массу в килограммах рассчитывают по геометрии в миллиметрах. Подробнее: [контракт массы и инерции сборки](../../docs/assembly-mass.ru.md).

Контракт сопряжений и жёсткой кинематики v10 описан в [Document Model v10](document-model-v10.md). Базовые элементы и импорт сканов описаны в [Document Model v7](document-model-v7.md); обратное проектирование сканов — в [отдельном контракте](scan-reverse-engineering.ru.md).
