# Модель документа v12

[Русский](#русский) · [English source](document-model-v12.md#english)

## Русский

Текущая версия документа — **v12**, определённая в [`cadyx/migrations.py`](../../cadyx/migrations.py). Версия оболочки проекта остаётся **v1**, графа сборки — **v3**. Версия схемы не равна ревизии конкретного проекта: `expected_revision` должна совпадать с сохранённой ревизией этого проекта.

В v12 добавлены сохраняемые рабочие плоскости эскизов YZ, CUSTOM и FACE с сохранением прежних эскизов XY/XZ, локальных координат и смещений. Канонические определения полей, правила привязки к грани, миграция v11→v12 и ограничения операций приведены в [контракте рабочих плоскостей](../../docs/sketch-workplanes.ru.md). Эта страница — точка входа для текущей версии, а не дубликат схемы.

Другие применимые контракты:

- [Формат проекта и сохранение](project-format-v1.ru.md).
- [Геометрия, импорт и экспорт](document-model-v7.ru.md), [параметры и перестроение](document-model-v8.ru.md).
- [Граф сборки](document-model-v9.ru.md), [сопряжения](document-model-v10.ru.md), [материалы](document-model-v11.ru.md).
- [Карта текущих возможностей](../../docs/README.md#русский).

Старые документы описывают контракт на момент его введения; более поздние версии и текущая реализация могут отменять приведённые там ограничения. Изменения модели проходят через общую Command System с проверкой ревизии, блокировкой проекта для редактирования и атомарным сохранением. Чтение и миграция только в памяти сами по себе не переписывают файлы пользователя.
