# Документ модели v13 / граф сборки v4

[English](document-model-v13.md) · [Русский](#русский)

## Русский

Документ v13 ввёл сохраняемые закрепление и видимость экземпляров. Текущая схема документа — v14; актуальная схема сопряжений и графа описана в [контракте v14](document-model-v14.ru.md).

- `grounded`: сохраняет зафиксированный экземпляр в его сохранённом положении при решении сопряжений. Если связь требует переместить закреплённый экземпляр, команда атомарно отклоняется. Жёсткое перемещение закреплённого экземпляра или его группы с закреплённой деталью запрещено; для допустимого относительного движения нужно менять координату соответствующего соединения.
- `visible`: управляет видимостью конкретного экземпляра. Скрытие экземпляра подсборки убирает всю вложенную ветку, не меняя видимость исходного тела или его геометрию.

Новые экземпляры создаются со значениями `grounded: false` и `visible: true`. Команда `set_assembly_instance_properties` меняет эти поля и имя детали через существующую транзакцию Core с проверкой ревизии. Диагностика кинематики возвращает ID закреплённых экземпляров и не включает их в глобальные жёсткие степени свободы.

Миграция документа v12 → v13 обновляет экземпляры графа v3 в памяти и назначает значения по умолчанию. Следующая успешная команда сохраняет миграцию обычным атомарным способом. Авторитетная схема и реализация находятся в [`cadyx/assemblies.py`](../../cadyx/assemblies.py), [`cadyx/assembly_mates.py`](../../cadyx/assembly_mates.py) и [`cadyx/command_assembly.py`](../../cadyx/command_assembly.py).

Эта версия не добавляет интерактивный браузерный редактор сборок или связи с геометрическими ссылками: для них нужны отдельные контракты и реализация.
