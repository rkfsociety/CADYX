# Импорт STL как референсной модели

Команда `import_stl` принимает либо имя STL-файла `.stl`, заранее помещённого в текущий проект, либо путь `source_path` к обычному локальному файлу `.stl` без символьных ссылок, вместе с точным `expected_sha256` в нижнем регистре. Необязательное поле `name` задаёт имя референсного тела. Обе формы требуют обычной блокировки проекта и точной ревизии. Для импорта файла проекта вычисляется и записывается хеш источника; файл остаётся нетронутым, а сохранённая геометрия сетки самодостаточна.

Если импортируется файл проекта, `file` разрешается через workspace текущего проекта. В происхождении элемента сохраняются относительное имя файла и рассчитанный SHA-256. Вкладка Files предлагает такой импорт наряду с действиями STEP и PLY.

Поддерживаются бинарный STL (в том числе с заголовком, начинающимся с `solid`) и строгий ASCII STL. Максимальный размер входа — 64 МиБ; отдельного ограничения на число треугольников нет, их количество ограничивается размером файла. До изменения документа отклоняются не конечные координаты, некорректная структура и вырожденные треугольники. Вершины объединяются при точном совпадении координат; координаты источника и масштаб сохраняются. STL не задаёт физических единиц, поэтому результат остаётся безразмерным, пока единицы не будут подтверждены отдельно.

Импортированное тело — референсная треугольная сетка с гранями `cadyx-mesh-v1`, не B-rep. В отличие от неё импорт PLY только с точками (`import_project_point_cloud`) сохраняет вершины для осмотра сцены, но не имеет граней и не подходит для получения сечений сетки или оценки отклонения сетки. См. [контракт сканирования и обратного проектирования](scan-reverse-engineering.ru.md).

Импортированную STL-сетку принимают существующие `create_sketch_from_scan_section`, `create_scan_sections`, `compare_body_to_scan` и `align_scan`. Выравнивание STL опирается на сохранённую исходную сетку, поэтому последующие изменения выравнивания каждый раз начинаются с исходных координат. Итоговую редактируемую модель следует строить по эскизам и твердотельным элементам; один импорт STL не восстанавливает параметрическую модель.

Регрессионные тесты: `tests/test_stl_reference.py`.
