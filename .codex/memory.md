# CADYX project memory

- Confirmed: CADYX uses a project-local Python 3.15 runtime and a native OCCT C ABI bridge on Windows x64. Reproducible setup and reviewed stable versions: `scripts/setup-runtime.ps1`, `scripts/runtime-versions.json`; runtime artifacts stay in ignored `.runtime/`. See [setup](../README.md).
- Confirmed: `CadyxCore` is shared by the web API and Agent API. `ProjectWorkspace` writes each project's metadata, document, revision, and command history together in `projects/<uuid>/project.json` using atomic replacement.
- Confirmed: `GET /api/v1/projects` and `GET /api/v1/agent/projects` list immediate directories without a CADYX `project.json` in `folders`. The web UI treats them as selectable projects; CADYX document inspection/leases/commands still require a persisted project record. See [architecture](../docs/architecture.md).
- Confirmed: folder projects expose direct regular files through the workspace file API. The browser previews binary little-endian PLY meshes and point clouds with a downsampled canvas renderer that fills the desktop workspace; drag orbits the camera, the wheel zooms, and a double-click resets the view. Source files are read-only. See [architecture](../docs/architecture.md) and `web/ply-preview.js`.
- Confirmed: edit leases persist in per-project SQLite sidecars and coordinate local host processes. The same transaction protects the entire Core command and recovery; expired leases stay locked until saved state and geometry validate. Timeout is fixed at acquisition; busy operations return PROJECT_BUSY after five seconds. SSE remains process-local. See [lease contract](../docs/architecture.md#edit-leases).
- Confirmed: Web API commands require a human lease; Agent API commands require an agent lease. Both invoke the same Command System.
- Confirmed: agent `/stop` persists a token fence in `.cadyx-agent.sqlite3` before waiting for the project guard, then validates saved state before releasing the agent lease. `/resume` validates an expected revision and issues a new lease whose commands require `expected_revision`. Legacy `/leases` remains compatible. Preserve both coordination sidecars while hosts run; stop older hosts before upgrading. Canonical contract: [safe agent stop/resume](../docs/architecture.md#safe-agent-stop-and-resume).
- Confirmed: the in-process `AgentRuntime` uses the `AgentProvider` protocol, runs bounded inspect/viewport/command tool calls, protects every command with the current revision, refreshes the lease heartbeat, and stops through the validated agent-stop path. No provider adapter is bundled. Canonical contract: [Agent Runtime](../docs/architecture.md#agent-runtime).
- Confirmed: sketch invariants live in `cadyx/sketches.py`; constraints check supplied geometry without solving it. Use `update_sketch_elements` to move constrained points together. Sequential migrations live in `cadyx/migrations.py`, with independent envelope/document versions. Workspace reads migrate copies and validate without writing; Document v1 upgrades to v2 and is persisted only on a successful command; the project envelope stays v1. Canonical schema and command contract: [Document Model v2](../docs/document-model-v2.md).
- Confirmed: the browser workspace displays Core-generated body meshes and XY sketch points/lines/circles through `GET .../viewport` and `web/viewport.js`, shared with PLY previews; Z is up, and scene refresh preserves camera state. See [viewport contract](../docs/viewport-api.md). It refreshes from project snapshots after SSE events; the UI shows status without an agent command feed. The Agent Runtime is an in-process Python API, not embedded in the web server; external agents may continue to use the Agent API. See [architecture](../docs/architecture.md).
- Confirmed: the browser is a read-only full-window detail viewer; model and property docks start collapsed. Agents create projects and edit document objects through the Agent API, and can fetch an isometric PNG scene image from `GET /api/v1/agent/projects/{id}/viewport.png` without a browser. The local host defaults to port `8888`. Canonical contracts: [Document Model v2](../docs/document-model-v2.md#browser-inspection-and-agent-api-editing), [viewport API](../docs/viewport-api.md), and [run instructions](../README.md).
- Confirmed: the Windows persistent host is registered with `scripts/manage-host-task.ps1` as an interactive at-logon Scheduled Task, loopback port `8888`, and restart-on-failure; it launches `pythonw.exe` directly, so no console appears and Task Scheduler tracks host lifetime. `scripts/run-host-background.py` captures stdout/stderr and rotates prior logs under `%LOCALAPPDATA%\CADYX`. Reinstall after moving the checkout or rebuilding the local runtime. Canonical lifecycle instructions are in [README](../README.md#keep-the-windows-host-running).
- Confirmed: `PrimitiveKernelAdapter` constructs and validates demo descriptors without B-reps; its viewport tessellation delegates to the native OCCT adapter.
- Confirmed: `OCCTKernelAdapter` is the default kernel (`OCPKernelAdapter` remains a compatibility alias). It creates and validates Open CASCADE B-reps from JSON-safe box descriptors and still validates saved `primitive-v1` boxes for compatibility.
- Confirmed user-provided Scan-to-CAD test data: `projects/knopkapylik/` contains `knopkapylik_mesh.ply` and `knopkapylik_pc.ply`. Use these inputs to test the first scan-based model after basic geometry checks pass; preserve the source files.
