# Обработка треугольных сеток для ИИ-агента

Обнаруживаемая команда `process_mesh` принимает `body_id`, `method` и необязательные `parameters`. Она выполняется через общий GeometryKernel, Command System, Agent API с проверкой ревизии и оболочку MCP. Инструменты предназначены агенту; дерево браузера показывает только реально выполненные операции и сохранённые результаты.

| Метод | Параметры | Поведение |
| --- | --- | --- |
| `clean` | `{}` | Объединяет точные дубликаты вершин XYZ, удаляет повторяющиеся треугольники и треугольники нулевой площади, уплотняет неиспользуемые вершины. |
| `remove_small_components` | `{min_triangles}` | Удаляет компоненты, связанные общими рёбрами, если в них меньше заданного числа треугольников (1–100000). Совпадение только вершиной не связывает компоненты. |
| `orient` | `{}` | Делает направление обхода согласованным внутри каждой компоненты по рёбрам. Отклоняет неориентируемый или неманифолдный вход. Не утверждает, что нормали направлены наружу. |
| `repair_orientation` | `{}` | Удаляет конфликтующие треугольники из циклов противоречия чётности в неориентируемых сетках, затем ориентирует оставшиеся треугольники. Отчёт содержит число удалённых треугольников. Вместо отсутствующих заплат появляются дополнительные открытые границы. |
| `smooth` | `{iterations, strength}` | Выполняет проходы сглаживания Таубина с коэффициентами `strength` и `-1.05 * strength`; 1–10 итераций, `strength` в диапазоне `(0, 0.5]`. Фиксирует вершины открытых границ. Отклоняет вырожденные, неманифолдные или несогласованно ориентированные входы, а также перевороты треугольников относительно исходной сетки. |

Операции принимают треугольные сетки не более чем из 200000 треугольников. В результате должны остаться треугольники; запрещено добавлять вырожденные треугольники нулевой площади и неманифолдные рёбра. Для сглаживания дополнительно проверяется сохранённый результат float32. Это не проверка самопересечений и не точное сохранение формы.

Каждая операция создаёт новое тело со ссылкой на исходник, скрывает исходник и сохраняет полноразмерный PLY с хешем. Записываются метод, параметры, хеш исходной геометрии, предшествующий элемент истории, количества до и после обработки, число связных компонент, границ, несогласованных направлений и вырождений. Сглаживание сообщает фактическое максимальное смещение вершины в неизменённой системе координат источника. Исходные тела и PLY остаются доступными. Если исходник меняется так, что нарушается сохранённая проверка, потомок не проходит проверку по хешу исходной геометрии.

Эти операции не заполняют отверстия, не определяют физический масштаб, не превращают сетку в OCCT-тело и не доказывают отсутствие самопересечений. Исторические операции служат записями инспекции; для следующего результата добавьте новую операцию.
