# Backlog инструментов эскиза CADYX

Список сохранён для последующего расширения CADYX по мере необходимости. Реализация всех пунктов не является текущей задачей. Это **список пожеланий,
а не реестр неподдерживаемых функций**: часть названий уже покрывается
существующими примитивами и командами, а для остальных требуется отдельное
уточнение контракта. Для фактической поддержки проверяйте
`GET /api/v1/agent/capabilities`, `cadyx/capabilities.py` и
[карту документации](README.md).

Названия и порядок перенесены из предоставленного списка; повторяющиеся пункты сохранены отдельно. Перед реализацией выбранного инструмента нужно уточнить его контракт по контексту использования и добавить адресные проверки.
